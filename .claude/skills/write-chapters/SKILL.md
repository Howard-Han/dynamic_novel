# 撰寫篇章與結局文本

對應 `.claude/rules/writing_details.md` 的寫作步驟 4 與全部寫作規則。執行前提：該小說的 `劇情樹狀圖.md` 已與使用者討論定案。

## 寫作流程

1. 讀取所有設定檔與 劇情樹狀圖.md，按圖中的篇章編號順序寫作。
2. **逐步與使用者討論**：每寫完一批篇章（建議 2~3 章）即與使用者確認內容是否需微調，不要一次寫完全部才給看。
3. 篇章寫入 篇章文本.md、結局寫入 結局文本.md，格式依 writing_details.md：
   - 篇章文本.md 按篇章編號條列，各篇章含：篇章文本、選擇題題目與選項。
   - 結局文本.md 按結局編號條列，各結局含：結局文本、結局圖片的路徑。

## 寫作時必守的規則（詳見 writing_details.md）

- 字數下限：結局 100 字、初始篇章 200 字、其他篇章 500 字。
- 結局以外各篇章的最後一段，要呈現主角進行抉擇的心理，並與選擇題高度相關。
- 「劇情解鎖」要素只能在玩家走到特定篇章後才提及。
- 主角性格（若設定未明列）受玩家選項影響，各分岐路徑的文風要反映累積的選擇傾向。
- 寫作中發現需新增的要素或配角，回補至 必要要素設定.md / 角色設定.md。

## 完成後

1. 回到 主要設定.md 補上「小說簡介」（150 字為限，引起閱讀興趣，不可提到後半段篇章與各結局的任何內容）。
2. 用 story-validator agent 對整部小說做最終審查（字數、路徑一致性、劇情衝突）。
